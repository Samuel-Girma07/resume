# Samuel Girma - Portfolio Website

A modern, responsive portfolio website showcasing my work as a Computer Science student and web developer.

## 🌟 Features

- **Single Page Application (SPA)** - Smooth page transitions with animated navigation
- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Interactive Elements** - Custom cursor, fluid background animations, and parallax effects
- **Project Showcases** - Dynamic sliders featuring StudyLens and TechShop Ethiopia
- **Modern UI/UX** - Glass morphism effects, gradient animations, and smooth transitions

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, animations, and responsive design
- **JavaScript (Vanilla)** - SPA navigation, WebGL effects, and interactive features
- **Font Awesome** - Icon library
- **Google Fonts** - Orbitron, Plus Jakarta Sans, and Syne typefaces

## 📂 Project Structure

```
├── index.html          # Main page (About section)
├── resume.html         # Resume/Experience page
├── projects.html       # Projects showcase page
├── contact.html        # Contact form page
├── style.css           # Main stylesheet
├── script.js           # Core JavaScript functionality
├── orb_effect.js       # Profile orb animation
├── interactive_dots.js # Interactive background effects
├── cv.pdf              # Downloadable resume
└── assets/             # Images and icons
```

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Samuel-Girma07/portfolio.git
```

2. Open `index.html` in your browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

3. Navigate to `http://localhost:8000`

## 📱 Responsive Design

The website is fully responsive with breakpoints at:
- Desktop: > 768px
- Mobile: ≤ 768px

Mobile features include:
- HUD-style navigation
- Optimized touch interactions
- Reduced animations for performance
- Adaptive layouts

## 🎨 Key Features

### Custom Cursor
Desktop users experience a custom magnetic cursor with smooth following animations.

### Fluid Background
WebGL-powered fluid simulation creates an interactive background effect (desktop only).

### Typewriter Effect
Animated subtitle text in the sidebar with blinking cursor.

### Timeline Animations
Staggered reveal animations for resume timeline items.

### Project Sliders
Auto-playing image carousels with manual controls for project showcases.
